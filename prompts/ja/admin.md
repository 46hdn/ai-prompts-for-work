# 総務・事務 向けAIプロンプト

下のプロンプトをコピーして、ChatGPT・Gemini・Claude・Copilot・Perplexity・Grokのチャット欄に貼ってください。`{{ }}` や（ここに…）の部分は、自分の内容に書き換えます。

## ビジネスメールの下書き

```
次の用件で、ビジネスメールを書いてください。
- 件名の案と本文（丁寧で簡潔、300字以内）
- 依頼なら、期限と依頼内容を明確に。断りなら、角が立たない言い方で

【用件と相手】
（ここに書く）
```

## お詫びメールの文面

```
次の状況で、お詫びのメールを書いてください。
- 最初にお詫び、次に事実の説明（言い訳にしない）、対応と再発防止、最後にもう一度お詫び
- 責任を認めすぎて不利にならないよう、事実の範囲で書く

【状況】
（ここに書く）
```

## 社内向けお知らせ

```
伝えることは、何が・いつ・誰が・何をするか・問い合わせ先。{{トーン:丁寧|親しみやすい|簡潔}}な文体でお願いします。
```

```
- 相手が返信しやすいよう、選ぶだけで済む形にする

【相手と用件、候補日時】
（ここに書く）
```

```
- 確認したい点を箇条書きで、期限を明記
- 相手の落ち度を責めない、事実ベースの書き方にする

【確認したい内容】
（ここに書く）
```

```

- 一手順につき動作は一つ、あいまいな言葉を避ける

```

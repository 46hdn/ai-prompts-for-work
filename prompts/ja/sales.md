# 営業 向けAIプロンプト

下のプロンプトをコピーして、ChatGPT・Gemini・Claude・Copilot・Perplexity・Grokのチャット欄に貼ってください。`{{ }}` や（ここに…）の部分は、自分の内容に書き換えます。

## 商談後のお礼メール

```
商談後に送るお礼メールを書いてください。
条件：
- 丁寧だが簡潔なビジネス文体、300字以内
- 本日話した要点を2点だけ振り返る
- 次のアクションと期限を明記する
- 押しつけがましい表現は避ける

【商談メモ】
（ここに商談のメモを貼り付け）
```

## 提案書の骨子づくり

```
以下の相手向けに、提案書の骨子（見出しと各見出しの要点）を作ってください。
- 相手の課題 → 解決策 → 期待できる成果 → 進め方 → 費用の順で構成する
- 各見出しに、書くべき内容を1〜2行で示す
- 不足している情報があれば、最後に質問として列挙する

【相手と課題】
（ここに書く）
```


## 新規アポイントの依頼メール

```
初めて連絡する相手に、面談のお願いメールを書いてください。
- 件名の案を3つ
- 冒頭で、なぜ連絡したのか（相手を選んだ理由）を一文で示す
- 面談で得られるメリットを具体的に一つ
- 候補日時を3つ提示する形にする
- 断りやすい一文を添える

【相手の情報と、こちらの目的】
（ここに書く）
```

## 断られた案件のフォローアップ

```
一度お断りをいただいた相手へ、関係を切らずに送る短いフォローメールを書いてください。
- 押し売りにならないこと
- 相手の判断を尊重する一文を入れる
- 役立ちそうな情報を一つだけ添える
- 200字以内

【これまでの経緯】
（ここに書く）
```

## 競合比較の整理

```

- 比較軸を5〜7個、私が選びやすいよう最初に提案する
- 表は「軸／自社／競合／お客様にとっての意味」の4列
- 事実が不確かな箇所は断定せず「要確認」と書く

【自社サービス】
（ここに書く）
【競合】
（ここに書く）
```

## 値引き要求への返し方

```
お客様から値引きを求められています。関係を保ちながら受け答えできる返答の選択肢を3案作ってください。
1. 価格を維持し、価値を伝える案
2. 条件の交換（納期・数量・契約期間など）を提案する案
3. 今回は難しいと丁寧に伝える案
それぞれ、そのまま使える返答文と、使う場面の目安を書いてください。

【状況】
（ここに書く）
```

## ヒアリング質問リスト

```
初回ヒアリングで確認すべき質問を、次の分類で15個前後作ってください。
- 現状と課題／目的とゴール／予算と時期／決裁の流れ／他社の検討状況
- 答えやすい順に並べる
- 「はい・いいえ」で終わらない聞き方にする

【相手の業種と、提供予定のもの】
（ここに書く）
```

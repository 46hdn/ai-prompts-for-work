# フリーランス・個人事業主 向けAIプロンプト

下のプロンプトをコピーして、ChatGPT・Gemini・Claude・Copilot・Perplexity・Grokのチャット欄に貼ってください。`{{ }}` や（ここに…）の部分は、自分の内容に書き換えます。

## 提案・見積の送付メール

```
新規のお客様へ、提案書と見積書を送るメールを書いてください。
- 相談への感謝、提案の要点（2〜3行）、添付の案内、返事の期限、次のステップ
- 丁寧で、簡潔に（300字以内）

【お客様と案件の概要】
（ここに書く）
```

## 納期・仕様変更のお願い

```
進行中の案件で、納期または仕様の変更をお願いするメールを書いてください。
- 事情の説明は事実だけ、代替案を2つ添える
- 追加の費用や日数が出る場合は、はっきり伝える

【状況】
（ここに書く）
```

## 請求メールと督促

```
{{取引先}}様への{{種類:請求のご案内|お支払いのご確認|支払期日を過ぎた場合のご連絡}}メールを書いてください。
対象は{{案件名}}、金額は{{金額}}、期日は{{期日}}です。
{{トーン:丁寧|やわらかめ|事務的}}な文体で、角が立たない一文を入れてください。
```

## 自己紹介と実績紹介文

```
次の情報から、依頼を検討している方向けの自己紹介文を書いてください。
- 誰の・どんな課題を解決できるか（最初の2行）
- 実績と強み、進め方、依頼の流れ
- 400字程度、事実の範囲で書き、誇張しない

【経歴・実績・得意なこと】
（ここに書く）
```

# Product & Project Mgmt — AI prompts

Copy any prompt below into ChatGPT, Gemini, Claude, Copilot, Perplexity or Grok. Replace the `{{ }}` parts and “(paste here)” with your own details.

## Meeting agenda

```
Create an agenda for the meeting below.
Include the goal (what must be decided), timed topics that fit in 45 minutes, and pre-reads.
Suggest which items could be handled asynchronously instead.

Meeting context:
(paste here)
```

## Clean meeting notes

```
Turn my rough notes into meeting minutes.
Sections: decisions, open questions, action items (owner and due date), FYIs.
Don't invent owners or dates; mark them "TBD" if missing.

Notes:
(paste here)
```

## Feedback for a teammate

```
Help me give feedback to {{Name}} in a {{Setting:1:1|Performance review|Quick chat}}.
What happened: {{Specific example}}
Structure: what went well, what to change, what I'd like next.
Focus on behavior, not personality. Give me two phrasings.
```

## PRD first draft

```
Draft a product requirements document for the idea below.
Sections: problem, users, goals and non-goals, requirements, success metrics, open questions, risks.
Mark anything that needs data as "(needs data)".

Idea:
(paste here)
```

## User story breakdown

```
Break the feature below into user stories.
Format: "As a ___, I want ___ so that ___", each with 2-4 acceptance criteria.
Order by what delivers value first, and flag anything that's too big to build in one sprint.

Feature:
(paste here)
```

## Prioritization help

```
Help me prioritize the items below.
Suggest 4 criteria, score each item in a table, and explain the top three.
I make the final call, so also list the assumptions that could change the order.

Items and context:
(paste here)
```

## Stakeholder update

```
Write a status update for stakeholders.
Format: one-line summary with status (green/yellow/red), progress, risks and blockers, decisions needed, next steps.
Be honest about slips; keep it under 200 words.

Project notes:
(paste here)
```

## Risk register

```
List the risks for the project below.
Table: risk / likelihood (L/M/H) / impact (L/M/H) / early warning sign / mitigation.
Then name the top three I should act on this week.

Project:
(paste here)
```

## Retrospective facilitation

```
Design a 45-minute retrospective for my team.
Include a warm-up, a structure for what went well / what didn't / what to try, and how to turn ideas into 2-3 owned actions.

Team context and recent sprint:
(paste here)
```

## Write OKRs

```
Draft OKRs from the goal below.
One objective and three measurable key results. Say how we'll track progress and when to review.
Flag any key result that measures activity instead of outcome.

Goal and context:
(paste here)
```

## Customer feedback themes

```
Read the feedback below and group it into themes.
For each theme: a short name, how many comments, two representative quotes, and a possible product response.
Separate what customers asked for from the underlying problem.

Feedback:
(paste here)
```

## Executive one-pager

```
Turn the material below into a one-page summary for executives.
Order: the conclusion in one line, three supporting points, the decision I need, and the next step.
No jargon; only the most important numbers.

Material:
(paste here)
```
